# py-trainer — «Программирование на Python» (переподготовка учителей)

Электронный учебник по образцу isu-trainer, та же база (Supabase) и та же учётная запись.

Версии: index.html (русский) и ky.html (кыргызский). Кыргызские тексты стоит показать носителю языка перед выдачей слушателям.

Как выложить:
1. Создайте репозиторий `py-trainer` на GitHub, загрузите в него все файлы из этой папки (кроме README.md, если не нужен).
2. Settings → Pages → Branch: main, папка / (root).
3. Адрес: https://dkanetova76-hue.github.io/py-trainer/
4. В репозитории isu-trainer замените `teacher.html` и `progress.js` файлами из папки `isu-trainer-update`.
   В `progress.js` репозиториев ct-trainer и kuod-trainer добавьте строку курса `py` в список ALL (см. строку с `id: 'py'`).
5. В кабинете преподавателя переключитесь на курс «Программирование», создайте группу и выдайте код слушателям.
Даты семестра — в plan.js или в «Настройках семестра» кабинета.
